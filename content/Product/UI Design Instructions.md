Design a complete UI/UX for an AI-powered business and execution platform called “Orelis Hub”.

IMPORTANT:
This is NOT a standard SaaS dashboard. Avoid generic layouts like Notion, ClickUp, Jira, or typical AI chatbot apps.

The product should feel like an AI operating system for thinking, planning, and executing business ideas and operations.

The UI should feel:
- spatial, not page-based
- intelligent and adaptive
- premium and futuristic
- minimal but powerful
- like an AI workspace, not a productivity tool

---

CORE DESIGN DIRECTION:

- No traditional SaaS sidebar-first layout
- Navigation should be minimal, contextual, or floating (command palette, radial menu, or compact top navigation)
- Pages should feel like “modes” of an AI system rather than static pages
- AI should be deeply embedded into the interface, not a separate chatbot box

---

LAYOUT PHILOSOPHY:

Instead of stacked sections or card dashboards, structure each screen using 3 conceptual layers:

1. Awareness Layer (top / primary focus)
- AI summary of current state
- key insights
- priorities for the user/business
- what matters right now

2. Action Layer (core execution layer)
- tasks generated by AI
- recommended actions
- blockers and progress tracking
- step-by-step execution guidance

3. Exploration Layer (secondary intelligence layer)
- ideas
- simulations
- research insights
- market data and trends

---

UI STYLE:

- Dark mode only
- Backgrounds: deep charcoal with soft gradients and subtle noise texture
- Elements should feel like they float in space
- Soft layering instead of harsh panels
- Minimal borders, soft contrast separation
- Accent colors: muted electric blue or purple glow (used sparingly)

---

TYPOGRAPHY:

- Modern sans-serif (Inter / SF Pro style)
- Strong hierarchy:
  - large headings for key insights
  - medium text for actions
  - small muted metadata

---

COMPONENT STYLE:

- Avoid repetitive SaaS-style cards
- Use flexible “intelligence blocks” instead of fixed cards
- Components can vary in size depending on importance
- AI-generated content should appear as structured insight blocks, not chat messages

Each AI output block should include:
- title
- short explanation
- optional confidence or priority indicator
- optional action button

---

AI INTEGRATION RULES:

- AI is a system layer, not a separate feature
- AI insights should appear inline across the interface
- AI should proactively surface:
  - opportunities
  - risks
  - priorities
  - recommendations
- AI messages should feel like system intelligence, not conversation bubbles

Example AI signals:
- “AI detected a high-impact opportunity”
- “Priority adjusted based on recent activity”
- “Execution bottleneck identified”

---

NAVIGATION RULES:

- Avoid permanent heavy sidebar UI
- Prefer:
  - command palette as primary navigation
  - floating minimal navigation elements
  - contextual navigation based on current mode

---

MODES (IMPORTANT CONCEPT):

Each section should feel like a mode of the system:

- Dashboard = Awareness Mode
- Tasks = Execution Mode
- Idea Launchpad = Exploration Mode
- Market Simulation = Analysis Mode
- AI Advisor = Intelligence Mode

Each mode can slightly change layout structure to match its purpose.

---

DESIGN GOAL:

The final product should feel like:

“A living AI operating system that helps users think, decide, and execute business ideas and operations in real time.”

It should NOT feel like:
- a productivity app
- a SaaS dashboard
- a chatbot wrapper

---

OUTPUT EXPECTATION:

Design full UI/UX structure including:
- layout system
- component system
- navigation system
- dashboard structure
- page structure for all modes
- visual style direction
